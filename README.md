# narraverse

narraverse is an experimental no-BS worldbuilding TUI (that's still in the works lol). For now only narrative editing is available with more to come in later updates.

## Installation.
Prerequisites:
- Rust/Cargo installed on your system (preferrably latest possible version)

### From source
```bash
    git clone https://codeberg.org/enmkdev/narraverse && cd narraverse && cargo install --path .
```
